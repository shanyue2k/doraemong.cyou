隐私政策

我们视用户的隐私安全为根本生命线，坚持执行经得起技术检验的“零日志”标准

🛡️ 庄严承诺：严格执行零日志记录政策

哆啦A梦网络加速器郑重声明：我们在任何情况下均不记录、不保存、不监控、不出售任何用户的网络使用日志！

1. 我们坚决不收集和保留的数据清单

当您连接并使用哆啦A梦加速专线时，我们的系统设计从底层杜绝了以下敏感信息的记录：

  • 无浏览记录：绝不记录您访问的任何具体网址、域名、页面或 API 请求。
  • 无通信内容：绝不解析、嗅探或存储您发送或接收的数据包、下载文件或交互信息。
  • 无 DNS 查询日志：所有 DNS 请求均通过加密通道由专属防污染无日志 DNS 服务器解析，不留存历史查询记录。
  • 无 IP 映射绑定：绝不记录您的本地原始公网 IP 与出口代理 IP 之间的动态绑定映射关系。
  • 无会话时间轴：绝不记录您的具体上线/下线精确时间戳或单次连接时长。

2. 纯内存运行与无状态架构

为了从物理架构上落实“零日志”原则，哆啦A梦的中继加速节点全面采用纯内存镜像系统运行。服务器的操作系统与加速核心均驻留于易失性内存中，杜绝传统机械硬盘或固态硬盘写入持久化日志。一旦服务器重启或断电，内存中的所有运行临时状态将在物理层面瞬间灰飞烟灭，无法恢复。

3. 我们仅保留的必要账户基础信息

为保障基础账号服务与计费正常运行，我们仅在数据库中保存以下最小化必要数据：

  • 账户邮箱：用于您登录控制台、找回密码及接收系统重要维护通知（建议使用无个人实名关联的常用邮箱）。
  • 套餐状态与总流量统计：仅记录套餐有效截止日期及当月已消耗的总流量数值（仅为数字累计量，绝无流量成分与明细）。
  • 加密凭证：密码采用不可逆的加盐哈希（Argon2 / bcrypt）加密保存，任何人（包括本平台管理员）均无法还原您的明文密码。

4. 您的权利与数据完全销毁

您拥有随时注销账户并彻底清除数据的权利。若您不再需要我们的服务，可在用户控制台申请注销账户。一旦注销，您的邮箱及相关计费条目将被永久性物理擦除。
